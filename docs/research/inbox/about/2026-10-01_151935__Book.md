# Spec-Driven Development

Промпт — это разговор. Спецификация — это контракт.

## Почему это критично для агентов

- Агент без спецификации = агент без критериев готовности.
- Спецификация — это не «документ для человека», а **источник контекста для модели**.
- Хорошая спецификация снижает количество итераций, стоимость и дрейф задачи.
