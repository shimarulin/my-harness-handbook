# Схема `models.json` для Pi Coding Agent

## Расположение

| Путь | Описание |
|---|---|
| `~/.pi/agent/models.json` | Пользовательские переопределения и кастомные провайдеры |
| `$PI_CODING_AGENT_DIR/models.json` | Если задана переменная `PI_CODING_AGENT_DIR` |

Файл перечитывается при каждом открытии `/model` — перезапуск не требуется.

## Корневая структура

```json
{
  "providers": {
    "<provider-id>": { ... }
  }
}
```

## Поля провайдера

| Поле | Тип | Описание |
|---|---|---|
| `baseUrl` | string | Базовый URL API (например, `http://localhost:4000/v1`) |
| `api` | string | Протокол: `openai-completions`, `openai-responses`, `anthropic-messages`, `google-generative-ai`, `google-vertex` |
| `apiKey` | string | Ключ, имя env-переменной (`$VAR`) или shell-команда (`!command`) |
| `models` | object[] | Список моделей. Если опущен — настройки провайдера переопределяют встроенный конфиг |
| `headers` | object | Кастомные HTTP-заголовки |
| `authHeader` | boolean | Если `true` — отправляет ключ в `Authorization: Bearer <key>` |
| `compat` | object | Флаги совместимости |

## Поля модели

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | ID, отправляемый в API (должен совпадать с именем модели в шлюзе) |
| `name` | string | Отображаемое имя |
| `contextWindow` | number | Размер контекстного окна в токенах |
| `maxTokens` | number | Максимум выходных токенов |
| `reasoning` | boolean | Поддерживает ли модель расширенное мышление |
| `input` | string[] | `["text"]` или `["text", "image"]` |
| `cost` | object | Цена за миллион токенов: `input`, `output`, `cacheRead`, `cacheWrite` |

## Флаги совместимости (`compat`)

| Флаг | Описание |
|---|---|
| `supportsStore` | Включить параметр OpenAI `store` |
| `supportsDeveloperRole` | Использовать роль `developer` вместо `system` (OpenAI o1/o3) |
| `supportsReasoningEffort` | Отправлять параметр `reasoning_effort` (OpenAI) |
| `supportsUsageInStreaming` | Ожидать поля usage в streaming-ответах |
| `maxTokensField` | Переопределить имя параметра (например, `max_completion_tokens`) |
| `openRouterRouting` | Метаданные маршрутизации OpenRouter (JSON object) |
| `vercelGatewayRouting` | Метаданные маршрутизации Vercel gateway (JSON object) |

## Пример: кастомный шлюз с fallback

```json
{
  "providers": {
    "my-gateway": {
      "name": "My Aggregated Gateway",
      "baseUrl": "http://localhost:4000/v1",
      "api": "openai-completions",
      "apiKey": "$GATEWAY_API_KEY",
      "compat": {
        "supportsDeveloperRole": false,
        "supportsReasoningEffort": false
      },
      "models": [
        {
          "id": "gpt-4o",
          "name": "GPT-4o",
          "reasoning": false,
          "input": ["text", "image"],
          "contextWindow": 128000,
          "maxTokens": 16384,
          "cost": {
            "input": 5.0,
            "output": 15.0,
            "cacheRead": 2.5,
            "cacheWrite": 5.0
          }
        },
        {
          "id": "claude-sonnet",
          "name": "Claude Sonnet",
          "reasoning": true,
          "input": ["text", "image"],
          "contextWindow": 200000,
          "maxTokens": 8192,
          "cost": {
            "input": 3.0,
            "output": 15.0,
            "cacheRead": 0.3,
            "cacheWrite": 3.75
          }
        }
      ]
    }
  }
}
```

## Важные замечания

1. **`cost` указывается в долларах за миллион токенов**, не за один токен. Если `cost` не указать, Pi будет показывать `$0.00` за сессию.
2. **`contextWindow` не запрашивается у сервера** — Pi использует только значение из `models.json`. По умолчанию подставляется 128 000 токенов, что обычно неверно для OpenAI-совместимых шлюзов.
3. **`apiKey` может быть shell-командой** — например, `!security find-generic-password -ws ...` для macOS Keychain.
4. **Секреты лучше хранить в env-переменных** — используйте `$VAR_NAME` вместо литерального ключа.
