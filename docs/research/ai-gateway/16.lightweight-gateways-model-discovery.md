# Лёгкие LLM-шлюзы с Model Discovery и поддержкой кастомных провайдеров

## Проблема

LiteLLM Proxy — мощный, но тяжёлый (Docker-образ ~1 ГБ, Python-зависимости). Его Model Discovery не работает для кастомных OpenAI-совместимых провайдеров (открытый feature request [#20064](https://github.com/BerriAI/litellm/issues/20064)).

## Лёгкие альтернативы

### `ldrouter` (LateDev Router)

**Установка:** `npx latedev-router` или Docker Compose

**Ключевые возможности:**
- Selective model discovery (Fetch → select → import) с Select All;
- OpenAI-совместимые и Anthropic-совместимые шлюзы;
- Virtual combos (fallback или weighted round-robin);
- Provider API keys encrypted at rest (AES-256-GCM);
- Rate limits: RPM, TPM, daily/monthly token quotas;
- SQLite, Prometheus/metrics, admin TOTP 2FA.

**Ссылки:**
- [ldrouter — npm](https://www.npmjs.com/package/ldrouter/v/1.11.8)

### `Ferro Labs AI Gateway`

**Установка:** `docker run` или `make run` из исходников

**Ключевые возможности:**
- OpenAI-style endpoints (`/v1/chat/completions`, `/v1/models`, `/v1/embeddings`, `/v1/images/generations`);
- Multi-provider routing с 6 стратегиями (single, fallback, loadbalance, conditional, least-latency, cost-optimized);
- Built-in resilience: per-target retry controls, circuit breakers;
- Storage: memory, SQLite, Postgres.

**Ссылки:**
- [aigateway — pkg.go.dev](https://pkg.go.dev/github.com/ferro-labs/ai-gateway@v0.6.6)

### `llmproxy` (lordraw77)

**Установка:** Flask-сервер, `providers.toml` для конфигурации

**Ключевые возможности:**
- Эмуляция HTTP API Ollama, OpenAI `/v1`, llama.cpp;
- Multi-model discovery: union моделей всех провайдеров;
- При нескольких провайдерах модели префиксуются как `provider:model`;
- Response cache (TTL & size), `/stats` dashboard.

**Ссылки:**
- [llmproxy — GitHub](https://github.com/lordraw77/llmproxy)

### `nanollm`

**Установка:** `npx nanollm --config /path/to/config.yaml`

**Ключевые возможности:**
- Chat/completions, responses, messages;
- Fallback-группы;
- Hot-reload конфига;
- Wildcard-модели (например, `gpt-*`);
- Per-model HTTP proxy.

**Ссылки:**
- [nanollm — npm](https://www.npmjs.com/package/nanollm/v/0.0.16)

### `@khanglvm/llm-router`

**Установка:** `npm i -g @khanglvm/llm-router@latest`

**Ключевые возможности:**
- Управление провайдерами через Web UI или CLI;
- Auto-discover models для кастомных OpenAI/Anthropic-совместимых API;
- Model aliases с weighted round-robin, quota-aware balancing, automatic fallback;
- Rate limiting per model;
- Local models (llama.cpp, GGUF).

**Ссылки:**
- [@khanglvm/llm-router — npm](https://www.npmjs.com/package/@khanglvm/llm-router/v/2.5.1)

### `femtollm` (jonnyzzz)

**Установка:** Go build, single static binary

**Ключевые возможности:**
- Discovery-based routing — скрапит `/v1/models` каждого бэкенда;
- **Имена моделей в конфиге не требуются**;
- Protocol conversion: Anthropic Messages API → OpenAI Chat Completions;
- Fallback: multiple backends per model;
- Zero dependencies, pure Go.

**Ссылки:**
- [femto-llm — GitHub](https://github.com/jonnyzzz/femto-llm)

### `Manifest LLM Gateway`

**Ключевые возможности:**
- Model discovery через `GET <base_url>/v1/models` → `data[].id`;
- Если сервер не экспонирует `/v1/models`, модели регистрируются вручную;
- Поддержка кастомных провайдеров.

**Ссылки:**
- [Manifest LLM Gateway — Custom Providers](https://manifest.build)

### `llm-conduit`

**Ключевые возможности:**
- Single-binary, optionally TLS-enabled;
- OpenAI-compatible API;
- Aggregated models: `GET /v1/models` перечисляет все routable-имена.

**Ссылки:**
- [llm-conduit — crates.io](https://crates.io/crates/llm-conduit)

### `vanex-lite`

**Ключевые возможности:**
- Ultra-light LLM API gateway в одном бинарнике;
- Embedded SQLite;
- Конвертация и форвардинг к upstream (OpenAI, Anthropic, Gemini, DashScope).

**Ссылки:**
- [vanex-lite — Docker Hub](https://hub.docker.com/r/vanexllm/vanex-lite)

### `local-llm-router`

**Ключевые возможности:**
- Минималистичный сервер на Rust;
- Роутинг OpenAI-совместимых и Ollama-нативных подключений;
- `POST /admin/refresh` — повторный запуск model discovery на всех бэкендах.

**Ссылки:**
- [local-llm-router — crates.io](https://crates.io/crates/local-llm-router)
