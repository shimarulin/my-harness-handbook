# llmproxy (lordraw77): лёгкий шлюз с multi-model discovery

## Что это

llmproxy — lightweight, high-performance LLM proxy for caching, automatic failover, cost tracking, and seamless integration between local and cloud AI providers.

Это lightweight Flask server, который эмулирует HTTP APIs Ollama, OpenAI `/v1` и llama.cpp, и прозрачно форвардит запросы к одному или нескольким upstream providers.

**Поддерживаемые провайдеры:**
- NVIDIA and any other OpenAI-compatible endpoint (OpenAI, Mistral, vLLM, Groq, OpenRouter, LM Studio, local Ollama/llama.cpp)
- Azure OpenAI
- Anthropic
- Google Gemini

**Ключевые возможности:**
- Multi-model discovery: union моделей всех провайдеров
- Automatic failover
- Response cache (TTL & size)
- Live `/stats` metrics dashboard

## Конфигурация

Провайдеры объявляются в `providers.toml`:

```toml
[[provider]]
name = "nvidia"
type = "openai_compatible"
base_url = "https://integrate.api.nvidia.com/v1"
api_key = "${NVIDIA_API_KEY}"
models = ["meta/llama-3.1-8b-instruct"]

[[provider]]
name = "anthropic"
type = "anthropic"
api_key = "${ANTHROPIC_API_KEY}"
models = ["claude-opus-4-8", "claude-sonnet-5"]
```

Путь к конфигу задаётся через `PROVIDERS_CONFIG`.

**Правила именования моделей:**
- С одним провайдером имена моделей остаются bare (без изменений).
- С двумя и более — префиксуются как `provider:model` для дизамбигуации.
- Per-model `alias` может переопределить префикс.

## Запуск

```bash
docker run -d --name llmproxy \
  -p 8000:8000 \
  -v $(pwd)/providers.toml:/app/providers.toml \
  -e PROVIDERS_CONFIG=/app/providers.toml \
  lordraw/llmproxy:latest
```

Или из исходников:

```bash
git clone https://github.com/lordraw77/llmproxy.git
cd llmproxy
pip install -r requirements.txt
python app.py
```

## Model Discovery

При запросе `/v1/models` llmproxy объединяет модели всех провайдеров (union). Модели доступны как:

```bash
curl http://localhost:8000/v1/models
```

## Ограничение для Pi

`llmproxy` не отдаёт `contextWindow`, `maxTokens` и `cost` в `/v1/models` в формате, который Pi ожидает. Для проброса в Pi потребуется:

1. Использовать `kosha-discovery` для обогащения метаданных.
2. Или вручную указать метаданные в `models.json`.
