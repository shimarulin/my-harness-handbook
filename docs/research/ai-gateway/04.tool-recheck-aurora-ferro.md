# Повторная проверка инструментов: Aurora, Ferro Labs и другие

## Контекст

Перепроверка списка инструментов из ранних результатов поиска по четырём критериям:
1. **Auto-discovery моделей** — шлюз сам запрашивает список моделей у провайдера.
2. **Кастомные OpenAI-совместимые сервисы** — поддержка любого endpoint.
3. **Fallback при ошибке** — автоматическое перенаправление.
4. **Полные метаданные** — цены, contextWindow, maxTokens для проброса в Pi.

## Результаты

### 🥇 Aurora OSS — основной кандидат

**Все четыре критерия выполнены.**

**Auto-discovery:**
> Set an API key as an environment variable. Restart Aurora. The provider and all its models appear automatically. No config files needed.

Провайдеры auto-discovered from environment variables. Set any provider's `_API_KEY` and restart — the provider and its default models appear automatically.

**Кастомные OpenAI-совместимые:**
14 provider types, включая vLLM, кастомные провайдеры, OpenAI-compatible endpoints.

**Fallback:**
> Automatic failover on 5xx/429 responses, or manual rules mapping failed provider+model to backups.

**Полные метаданные:**
- Cost tracking, guardrails, semantic caching — всё в одном binary.
- Model aliases, overrides, fallback.
- Provider pools: load balancing между API-ключами (round-robin, least-loaded, weighted).

**Лёгкость:**
- Go, 55x faster than LiteLLM.
- OSS edition production-ready — auto-discovery, provider pools, semantic caching, guardrails, audit logging, all under Apache 2.0.
- Single binary + Docker, `npm install -g iaurora`.

**Ограничение:** admin dashboard может быть обязателен для настройки fallback-правил.

### 🥈 Ferro Labs AI Gateway — альтернатива

**Три из четырёх критериев выполнены; метаданные не подтверждены.**

- **Auto-discovery:** `DiscoveryProvider` с `DiscoverModels(ctx) ([]ModelInfo, error)` — live enumeration via provider API. `ConfiguredModelProvider` — authority for local/custom models.
- **Кастомные OpenAI-совместимые:** `ConfiguredModelProvider` для local/custom моделей. 30 providers, 2,500+ models.
- **Fallback:** Fallback (w/ exponential backoff), Weighted Load Balancing, Conditional (model-based). Per-target retry, failover, model aliases.
- **Лёгкость:** Go, single binary, predictable latency, minimal resource usage. One-line install для Linux/macOS/Windows, Homebrew, Docker, .deb/.rpm/.apk пакеты.
- **Кастомные OpenAI-совместимые:** нет отдельного типа `custom_openai`. Вместо этого можно переопределить `BASE_URL` любого OpenAI-совместимого провайдера (например, `deepseek`) на адрес кастомного сервиса. См. `docs/notes/ferro-labs-custom-provider.md`.
- **Метаданные:** Не подтверждено, что `/v1/models` возвращает cost/contextWindow/maxTokens.

### RouteHub — дополнение для обогащения метаданных

- **Live model catalog:** `get_model_info` читает context windows, `get_all_models` queries each provider's own models API.
- **20+ providers** через официальный OpenAI SDK, any OpenAI-compatible server.
- **Python library**, 3 direct dependencies: openai, pydantic, tiktoken.
- **383x faster imports** than LiteLLM, 5.5x faster first response.

**Ссылки:**
- [RouteHub — GitHub](https://github.com/The-Swarm-Corporation/RouteHub)
- [RouteHub — PyPI](https://pypi.org/project/routehub/)

### Отклонены

| Инструмент | Причина |
|---|---|
| Portkey AI Gateway | Auto-discovery не для кастомных провайдеров; метаданные не подтверждены |
| LLM Router (radlab) | Auto-discovery через models-config.json (ручной); метаданные не подтверждены |
| OpenHinge | Auto-discovery не подтверждён; метаданные не подтверждены |
| Starport | Метаданные не подтверждены; основная документация на pkg.go.dev |
| anymodel-py | Не LLM-шлюз; не по теме |
| JAiRouter | Auto-discovery не подтверждён; метаданные не подтверждены |
| nexus (alayrasystems) | Model Registry есть, но auto-discovery из healthy backends требует проверки |
| Proxym | Auto-discovery не подтверждён; FastAPI, не single-binary |
| StratifyAI | Auto-discovery не подтверждён; метаданные не подтверждены |

## Итоговая рекомендация

**Основной:** Aurora OSS — единственный, кто явно удовлетворяет всем четырём критериям.

**Альтернатива:** Ferro Labs AI Gateway — если Aurora не подойдёт.

**Дополнение:** RouteHub — для обогащения `models.json` метаданными, если Aurora/ Ferro не отдают достаточно.
