# Portkey AI Gateway: настройка и использование

## Что это

Portkey AI Gateway — open-source AI-шлюз, который предоставляет единый API для 200+ моделей от всех крупных провайдеров. Поддерживает три формата API: OpenAI Chat Completions, OpenAI Responses и Anthropic Messages — с автоматической трансляцией между ними.

**Ключевые возможности:**
- Единый эндпойнт для OpenAI, Anthropic, Gemini, Mistral, Groq, Ollama и др.
- Fallback и load balancing между таргетами.
- Custom hosts: маршрутизация к приватным/локальным моделям.
- Guardrails, кэширование, аналитика.
- Self-hosted через Docker или Node.js.

## Быстрый старт

### Docker (рекомендуемый способ для машины разработчика)

```bash
docker run -d --name portkey-gateway \
  -p 8787:8787 \
  -e LOG_LEVEL=debug \
  portkeyai/gateway:latest
```

Шлюз будет доступен по адресу `http://localhost:8787`.

### Docker Compose

```yaml
version: '3'
services:
  web:
    ports:
      - "8787:8787"
    image: "portkeyai/gateway:latest"
    restart: always
    volumes:
      - ./conf.json:/app/conf.json
      - ./logs:/app/logs
```

## Конфигурация

Portkey использует JSON-конфигурацию. Пример с fallback между провайдерами:

```json
{
  "strategy": {
    "mode": "fallback"
  },
  "targets": [
    {
      "provider": "openai",
      "api_key": "sk-xxxxx",
      "override_params": {
        "model": "gpt-4o"
      }
    },
    {
      "provider": "anthropic",
      "api_key": "sk-ant-xxxxx",
      "override_params": {
        "model": "claude-sonnet-4-20250514"
      }
    }
  ]
}
```

## Custom hosts (локальные модели)

Для маршрутизации к локально запущенным моделям используется параметр `custom_host`:

```json
{
  "strategy": {
    "mode": "fallback"
  },
  "targets": [
    {
      "provider": "openai",
      "custom_host": "http://localhost:11434/v1",
      "forward_headers": ["Authorization"]
    },
    {
      "provider": "openai",
      "api_key": "sk-xxxxx"
    }
  ]
}
```

**Важно:** URL должен включать версию пути (`/v1`). Portkey автоматически добавляет `/chat/completions` и другие эндпойнты.

При использовании Portkey SaaS маршрутизация к приватным/внутренним IP-адресам не поддерживается. Для гибридных и air-gapped развёртываний используется allowlist `TRUSTED_CUSTOM_HOSTS`.

## Использование с OpenAI SDK

```python
from portkey_ai import Portkey

portkey = Portkey(
    api_key="PORTKEY_API_KEY",
    provider="openai",
    custom_host="http://localhost:11434/v1"
)

response = portkey.chat.completions.create(
    model="llama3",
    messages=[{"role": "user", "content": "Hello!"}]
)
```
