# RouteHub: обогащение `models.json` метаданными

## Что это

RouteHub — Python-библиотека от Swarms (Apache 2.0, Python 3.10+). Позиционируется как быстрая альтернатива LiteLLM. **Импорт за ~5.5 мс** (в 383 раза быстрее LiteLLM), 5.5x faster first response, 3.9x less memory.

**Ключевые возможности:**
- Live model catalog: `get_model_info` reads context windows, `get_all_models` queries each provider's own models API.
- 20+ providers через официальный OpenAI SDK с теми же именами функций.
- any OpenAI-compatible server.
- Только 3 direct dependencies: openai, pydantic, tiktoken.

## Установка

```bash
pip install routehub
```

## Использование

```python
from routehub import get_model_info, get_all_models

# Список всех моделей
models = get_all_models()

# Информация о модели
info = get_model_info("gpt-4o")
print(info["context_window"])
print(info["cost"])
```

## Интеграция с Pi

1. Получите список моделей из Aurora/Ferro через `/v1/models`.
2. Обогатите contextWindow и cost через RouteHub.
3. Запишите результат в `~/.pi/agent/models.json`.

```python
import requests
import json
import os
from routehub import get_model_info

# Aurora
aurora_models = requests.get("http://localhost:8080/v1/models").json()["data"]

providers = {
    "aurora": {
        "baseUrl": "http://localhost:8080/v1",
        "api": "openai-completions",
        "apiKey": "$AURORA_MASTER_KEY",
        "models": []
    }
}

for m in aurora_models:
    model_id = m["id"]
    info = get_model_info(model_id)
    providers["aurora"]["models"].append({
        "id": model_id,
        "name": m.get("name", model_id),
        "contextWindow": info.get("context_window", 128000),
        "maxTokens": info.get("max_tokens", 16384),
        "reasoning": info.get("reasoning", False),
        "input": info.get("input", ["text"]),
        "cost": info.get("cost", {"input": 0, "output": 0, "cacheRead": 0, "cacheWrite": 0})
    })

os.makedirs(os.path.expanduser("~/.pi/agent"), exist_ok=True)
with open(os.path.expanduser("~/.pi/agent/models.json"), "w") as f:
    json.dump({"providers": providers}, f, indent=2)
```
