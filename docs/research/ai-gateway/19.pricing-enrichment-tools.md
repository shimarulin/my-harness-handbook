# Инструменты обогащения ценами и метаданными

## llmux

**Что это:** Шлюз с live auto-synced price catalog; возвращает cost в каждом `usage` block.

**Precedence источников:**
```
override (manual) > provider API (Azure) > LiteLLM (direct) > OpenRouter (margin) > built-in seed
```

**Route-aware:** через OpenRouter — margin-inclusive цена; BYO-key — авторитетная прямая цена.

**Эндпойнты:**
- `GET /v1/models` — catalog-backed list with pricing + capabilities.
- `GET /v1/catalog.json` — merged catalog as open JSON.

**Конфиг:**
```json
{
  "pricing": {
    "sync_interval_minutes": 360,
    "catalog_path": "catalog.json",
    "sources": [
      "https://openrouter.ai/api/v1/models",
      "https://raw.githubusercontent.com/BerriAI/litellm/main/model_prices_and_context_window.json"
    ],
    "overrides": {
      "openai/gpt-4o": { "input_per_mtok": 2.5, "output_per_mtok": 10.0 }
    }
  }
}
```

**Источник:** [llmux — GitHub](https://github.com/vul-os/llmux)

## @vladar107/claudescope

**Что это:** Pricing для Claude Code, Codex, opencode с auto-refresh из LiteLLM community price table.

**Provider override:** если агент записал provider и он совпадает с `providers` map в `pricing.json` — применяется zero-rate. Shipped defaults для local runtimes: ollama, lmstudio, llama.cpp, vllm, oss, local, mlx.

**Источники цен:**
- `~/.claudescope/pricing.fetched.json` — auto-refresh daily из LiteLLM.
- `~/.claudescope/pricing.json` — user-editable, takes precedence.

**Источник:** [claudescope — npm](https://www.npmjs.com/package/@vladar107/claudescope)

## @pydantic/genai-prices

**Что это:** Расчёт цены по usage-объекту. Custom pricing objects для моделей, отсутствующих в каталоге.

**Источник:** [genai-prices — npm](https://www.npmjs.com/package/@pydantic/genai-prices)

## @reaatech/otel-cost-exporter-pricing

**Что это:** Pricing table management с bundled provider data (OpenAI, Anthropic, Google, Bedrock, Azure) + custom YAML overrides.

**Источник:** [otel-cost-exporter-pricing — npm](https://www.npmjs.com/package/@reaatech/otel-cost-exporter-pricing)

## openai-cost-calculator

**Что это:** Exact, auditable USD cost calculation across 13 billing providers. Prices pulled automatically from each provider's official pricing API or documentation.

**Источник:** [openai-cost-calculator — PyPI](https://pypi.org/project/openai-cost-calculator/)

## LLM Pricing Scraper API (Apify)

**Что это:** Парсинг цен 400+ AI-моделей; price comparison across every provider hosting the same model.

**Источник:** [LLM Pricing Scraper — Apify](https://apify.com/llm-pricing-scraper)

## crawl4ai (для кастомных провайдеров)

**Что это:** LLM-friendly web crawler с `LLMExtractionStrategy` — можно использовать любой provider, который поддерживает LiteLLM, для извлечения названий моделей и их цен из документации.

**Источник:** [crawl4ai — GitHub](https://github.com/unclecode/crawl4ai)
