# Инструменты отслеживания стоимости и токенов

## inferrail

**Что это:** Self-hosted OpenAI-compatible gateway; измеряет стоимость каждого запроса и атрибутирует её customer/workflow/feature — без хранения промптов.

**Quickstart:**
```bash
pip install inferrail
export INFERRAIL_GATEWAY_TOKEN="$(python -c 'import secrets; print(secrets.token_hex(32))')"
inferrail serve --quickstart
```

**Demo (без ключа):**
```bash
inferrail demo
```

**Receipt содержит:** provider, model, input tokens, output tokens, cost, customer, prompt stored, response stored.

**Источник:** [inferrail — PyPI](https://pypi.org/project/inferrail/)

## tracetokens

**Что это:** Open-source AI observability & gateway platform. Track exact token consumption, micro-dollar costs, streaming TTFT latency, PII guardrails.

**Провайдеры:** OpenAI, Anthropic, Google Vertex AI/Gemini, DeepSeek, Groq, local models.

**Установка:** 1-line Python SDK + Universal AI Gateway Proxy.

**Источник:** [tracetokens — PyPI](https://pypi.org/project/tracetokens/)

## @bryxen/pulse

**Что это:** Self-hosted AI gateway в single Bun process. OpenAI- и Anthropic-compatible, audit logs, live dashboards, per-token cost tracking.

**Cost tracking:** Per-model input/output/cache pricing, rolled up by session, model, user.

**Источник:** [@bryxen/pulse — npm](https://www.npmjs.com/package/@bryxen/pulse)

## OngoingAI Gateway

**Что это:** Open-source AI gateway для tracing, cost visibility, audit-ready logs. Works with OpenAI, Anthropic, OpenAI-compatible APIs.

**HTTP Analytics API:** Query traces plus usage, cost.

**Источник:** [OngoingAI Gateway — pkg.go.dev](https://pkg.go.dev/github.com/ongoingai/gateway)

## LLM Gateway (llmgateway.io)

**Что это:** Route, manage, analyze LLM requests. Unified API gateway with built-in analytics, caching, cost tracking.

**Analytics:** Cost, request, token breakdowns by model, key, member. Summary cards for cost, tokens, requests, error rate.

**MCP Server:** `get-usage` — request, token, error, cache-hit, cost totals; daily/hourly series; most-used provider, model, coding app.

**Источник:** [LLM Gateway](https://llmgateway.io)

## any-llm-gateway

**Что это:** Budgeting, analytics, access management for any-llm. OpenAI-compatible Completions API.

**Источник:** [any-llm-gateway — Mozilla AI](https://blog.mozilla.ai/any-llm-gateway)

## Portkey

**Что это:** Enterprise-grade cost tracking, observability. Real-time cost tracking and per-user attribution.

**Источник:** [Portkey](https://portkey.ai)
