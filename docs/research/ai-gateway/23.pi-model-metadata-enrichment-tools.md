# Инструменты обогащения метаданных для `models.json`

## kosha-discovery

**Что это:** Библиотека/CLI/HTTP API для обнаружения AI-моделей across providers и обогащения данными о ценах.

**Ключевые возможности:**
- Dynamic discovery — fetches real model lists from provider APIs.
- Pricing enrichment — fills in costs and context windows from LiteLLM's community-maintained dataset.
- Model aliases, cheapest routing, local LLM scanning.

**Использование:**
```bash
kosha serve --port 3000
curl http://localhost:3000/models
```

**Источник:** [kosha-discovery — npm](https://www.npmjs.com/package/@sriinnu/kosha-discovery)

## litellm-controller (litellmctl)

**Что это:** CLI для LiteLLM Proxy: управление моделями, маршрутами и метаданными (цены, контекстные окна).

**Ключевые возможности:**
- Приоритетное слияние нескольких Python-скриптов для генерации `model_prices_and_context_window.json`.
- Динамическое ценообразование (например, DeepSeek peak/off-peak).
- Визуальный редактор (`default.py`),批量 настройка из Provider/Upstream.
- Неинтерактивный экспорт: `litellmctl metadata-gen`.

**Источник:** [litellm-controller — PyPI](https://pypi.org/project/litellm-controller/)

## models.dev

**Что это:** Публичный каталог метаданных моделей (цены, контекстные окна, возможности).

**API:** `https://models.dev/api.json`

**Используется в:**
- `pi-autofill-model-metadata` (явные маппинги)
- `@fe-essential/pi-custom-provider-manager`
- `better-custom-provider`

## LiteLLM cost map

**Файл:** `model_prices_and_context_window.json` в репозитории LiteLLM.

**Использование:** источник цен и context windows для известных моделей. LiteLLM auto-sync подтягивает обновления без перезапуска.

**Ссылка:** [LiteLLM Add Model Pricing](https://docs.litellm.ai/docs/provider_registration/add_model_pricing)

## Sub2API metadata repository

**Репозиторий:** `Wei-Shaw/model-price-repo`

**Использование:** источник цен и метаданных для `pi-openai-api-models-sync` по умолчанию.

**Ссылка:** [pi-openai-api-models-sync — GitHub](https://github.com/riverscn/pi-openai-api-models-sync)
