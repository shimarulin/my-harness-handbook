# LiteLLM Proxy + Pi Coding Agent: пошаговая интеграция

## Предварительные требования

- Pi Coding Agent 0.81.0 или новее;
- Запущенный LiteLLM Proxy (см. `docs/research/ai-gateway/litellm-proxy.md`);
- API-ключ LiteLLM (master key или virtual key).

## Шаг 1: Установка расширения

```bash
pi install npm:pi-provider-litellm
```

Или для установки только в проект (`.pi/settings.json`):

```bash
pi install -l npm:pi-provider-litellm
```

## Шаг 2: Вход в LiteLLM

Внутри Pi:

```
/login litellm
```

Выберите **«Sign in with an API key»** и введите:
- **Base URL:** `http://localhost:4000` (или адрес вашего LiteLLM);
- **API key:** ваш LiteLLM master key или virtual key.

Учётные данные сохранятся в `~/.pi/agent/auth.json`.

### Enterprise SSO

Если ваш LiteLLM требует SSO/OAuth:

```
/login litellm
# Выбрать "Sign in with LiteLLM SSO"
# Ввести URL прокси
# Пройти аутентификацию в браузере
# Скопировать токен и вставить в промпт
```

При генерации virtual key результат `sk-...` сохраняется как учётные данные.

## Шаг 3: Проверка

```
pi --list-models
```

Вы должны увидеть модели из вашего LiteLLM Proxy с полными метаданными (context window, max tokens, цены).

## Как работает discovery

Расширение пробует эндпойнты в следующем порядке:

1. **`/model/info`** — admin-эндпойнт LiteLLM, возвращает богатые метаданные:
   - `context_window`;
   - `max_input_tokens`;
   - `max_output_tokens`;
   - `input_cost_per_token`;
   - `output_cost_per_token`;
   - `litellm_provider`;
   - `supports_function_calling`;
   - `supports_vision`.

2. **`/v1/models`** — при 401/403/404 откатывается к OpenAI-совместимому эндпойнту.

3. **`/health` + per-endpoint `/model/info`** — для старых версий LiteLLM.

## Формат `models.json` после discovery

После успешного discovery `models.json` будет содержать полную информацию:

```json
{
  "providers": {
    "litellm": {
      "baseUrl": "http://localhost:4000",
      "api": "openai-completions",
      "apiKey": "$LITELLM_MASTER_KEY",
      "models": [
        {
          "id": "gpt-4o",
          "name": "GPT-4o",
          "contextWindow": 128000,
          "maxTokens": 16384,
          "reasoning": false,
          "input": ["text", "image"],
          "cost": {
            "input": 5.0,
            "output": 15.0,
            "cacheRead": 2.5,
            "cacheWrite": 5.0
          }
        }
      ]
    }
  }
}
```

## Ручная настройка (если discovery не работает)

Если `/model/info` недоступен (например, используется только virtual key без admin-прав), можно указать модели вручную:

```json
{
  "providers": {
    "litellm": {
      "baseUrl": "http://localhost:4000",
      "api": "openai-completions",
      "apiKey": "$LITELLM_MASTER_KEY",
      "compat": {
        "supportsDeveloperRole": false,
        "supportsReasoningEffort": false
      },
      "models": [
        {
          "id": "gpt-4o",
          "name": "GPT-4o (via LiteLLM)",
          "reasoning": false,
          "input": ["text", "image"],
          "contextWindow": 128000,
          "maxTokens": 16384,
          "cost": {
            "input": 5.0,
            "output": 15.0,
            "cacheRead": 2.5,
            "cacheWrite": 5.0
          }
        },
        {
          "id": "claude-sonnet",
          "name": "Claude Sonnet (via LiteLLM)",
          "reasoning": true,
          "input": ["text", "image"],
          "contextWindow": 200000,
          "maxTokens": 8192,
          "cost": {
            "input": 3.0,
            "output": 15.0,
            "cacheRead": 0.3,
            "cacheWrite": 3.75
          }
        }
      ]
    }
  }
}
```

## Полезные команды

| Команда | Описание |
|---|---|
| `/login litellm` | Вход в LiteLLM |
| `pi --list-models` | Список доступных моделей |
| `Ctrl+L` | Переключение модели внутри Pi |
| `Ctrl+P` | Циклическое переключение моделей |
