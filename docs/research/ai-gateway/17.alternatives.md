# Альтернативные шлюзы: обзор и сравнение

## 9Router

**Что это:** Self-hosted open-source альтернатива OpenRouter. Один OpenAI-совместимый эндпойнт для 60+ LLM-провайдеров, zero markup на использование, bring-your-own-keys.

**Особенности:**
- Один контейнер (SQLite вместо Postgres+Redis).
- Management dashboard для ключей, routing tiers и usage.
- Автоматический fallback.
- MIT-лицензия.
- Деплой в один клик (Railway, Docker).

**Ссылки:**
- [9Router — Railway](https://railway.com/deploy/9router-self-hosted-openrouter-alternative--9router-openrouter-alternative)
- [9Router GitHub](https://github.com/9router)

## OpenHinge

**Что это:** Self-hosted AI-шлюз, который объединяет нескольких LLM-провайдеров за единым OpenAI-совместимым API. Позволяет использовать собственные подписки (Claude Pro, ChatGPT Plus, Gemini) и API-ключи.

**Особенности:**
- OAuth-вход через существующие подписки (Claude, OpenAI, Gemini).
- «Souls» — AI-персоны с системными промптами и выделенными эндпойнтами.
- Fallback routing: провайдеры имеют приоритет, при ошибке запрос уходит следующему здоровому.
- Health monitoring без расхода квоты.
- Zero external dependencies: встроенная SQLite, без Redis/Postgres/Docker.
- CLI и веб-дашборд.

**Ссылки:**
- [OpenHinge — npm](https://www.npmjs.com/package/openhinge)

## Routerly

**Что это:** Self-hosted LLM-шлюз с интеллектуальной маршрутизацией, real-time cost tracking и бюджетными лимитами. Drop-in совместим с OpenAI и Anthropic API.

**Особенности:**
- Intelligent routing: до 9 политик (cheapest, capability, health, performance, context, budget-remaining, fairness).
- Real-time cost tracking: token-level цены per model, per project.
- Budget enforcement: hard limits (hourly/daily/monthly/per-request).
- Content guardrails и PII scrubbing.
- Notification system (Slack, Teams, PagerDuty, Discord, email).
- Zero database: конфиг и данные в JSON-файлах.
- Web dashboard + Admin CLI.
- Prometheus metrics.

**Ссылки:**
- [Routerly — Docker Hub](https://hub.docker.com/r/inebrio/routerly)

## LLM Router (paularlott)

**Что это:** Унифицированный шлюз на Go, агрегирующий多个 LLM-провайдеров за единым эндпойнтом. Клиенты используют предпочитаемый протокол (OpenAI или Anthropic Messages), шлюз обрабатывает маршрутизацию, трансляцию протоколов и балансировку.

**Особенности:**
- Multi-provider: OpenAI, Claude, Gemini, Ollama, Mistral, ZAi.
- Protocol translation: OpenAI ↔ Anthropic Messages.
- Weight-based load balancing.
- Smart routing: модель `auto` + Scriptling для выбора провайдера по тегам, нагрузке и содержимому запроса.
- MCP Aggregator: агрегация инструментов с нескольких remote MCP-серверов.
- Responses API и Conversations API.
- Admin UI (опционально).
- Homebrew, бинарники для macOS/Linux/Windows.

**Ссылки:**
- [llmrouter — pkg.go.dev](https://pkg.go.dev/github.com/paularlott/llmrouter@v0.1.3)
- [llmrouter GitHub](https://github.com/paularlott/llmrouter)

## llm-proxy (thelonelyghost)

**Что это:** Аутентифицирующий прокси на Go, предоставляющий OpenAI-совместимый API для подключаемых LLM-бэкендов. Предназначен для запуска на той же машине, что и coding-агенты.

**Особенности:**
- OpenAI API compliance: все ответы нормализуются к спецификации OpenAI.
- Prefix-based model routing: `<backend>/<model>` (например, `copilot/gpt-4o`).
- HCL2-конфигурация: один файл или директория `*.hcl`, env-интерполяция для секретов.
- Plugin system: out-of-process провайдер-плагины.
- Secure defaults: привязка к `127.0.0.1:4980`, удаление клиентских Authorization headers.
- Backends: OpenAI-compatible (built-in), GitHub Copilot (plugin), IBM Bob (plugin).

**Ссылки:**
- [llm-proxy — pkg.go.dev](https://pkg.go.dev/github.com/thelonelyghost/llm-proxy@v1.0.0)

## Petsitter

**Что это:** OpenAI-совместимый прокси, который накладывает «трюки» (pluggable transformations) поверх языковых моделей, давая им возможности, которых у них нет изначально.

**Особенности:**
- Tool calling для моделей без нативной поддержки.
- JSON mode: принудительный валидный JSON с retry.
- Code validator: самовосстанавливающаяся валидация.
- Context manipulation и prompt engineering.
- Динамическая маршрутизация между моделями.
- GUI для модификации трюков и логов.
- Secrets protector: обнаружение и псевдонимизация секретов/PII.

**Ссылки:**
- [Petsitter — PyPI](https://pypi.org/project/petsitter/0.5.1/)
