# kosha-discovery: обогащение `models.json` метаданными

## Что это

Kosha (कोश — treasury/repository) — библиотека/CLI/HTTP API для автоматического обнаружения AI-моделей across providers, разрешения credentials и обогащения моделей данными о ценах.

**Ключевые возможности:**
- Dynamic discovery — fetches real model lists from provider APIs
- Pricing enrichment — fills in costs and context windows from litellm's community-maintained dataset
- Model aliases — `sonnet` → `claude-sonnet-4-20250514`
- Cheapest routing — rank cheapest eligible models for tasks like embeddings or image generation
- Local LLM scanning — detects Ollama models alongside cloud providers
- Three access patterns — library, CLI tool, HTTP API

## Установка

```bash
pnpm add kosha-discovery
```

## Использование

### CLI

```bash
kosha discover          # discover all providers
kosha list              # list models
kosha list --provider anthropic  # filter by provider
kosha search gemini     # fuzzy search
kosha model sonnet      # model details
kosha cheapest --role embeddings  # cheapest for a task
kosha serve --port 3000 # start HTTP API
```

### HTTP API

```bash
kosha serve --port 3000
```

Затем:

```bash
curl http://localhost:3000/models
```

### Auto-Fetch JSON Snapshot

```bash
# One-shot
pnpm run autofetch:once

# Custom output/provider
pnpm run autofetch:once -- --provider openai --output ./data/openai-latest.json

# Continuous loop (default 3600s)
pnpm run autofetch -- --interval-seconds 900
```

По умолчанию записывает JSON в `./data/kosha-latest.json`.

## Интеграция с Pi

1. Запустите `kosha serve --port 3000`.
2. Запросите `/models` для получения списка с ценами и context windows.
3. Объедините с данными из Manifest `/v1/models?cost=true`.
4. Запишите результат в `~/.pi/agent/models.json`.

Пример скрипта:

```python
import requests
import json
import os

# Kosha
kosha_resp = requests.get("http://localhost:3000/models")
kosha_models = {m["id"]: m for m in kosha_resp.json()}

# Manifest
manifest_resp = requests.get(
    "http://localhost:2099/v1/models?cost=true",
    headers={"Authorization": f"Bearer {os.environ['MANIFEST_KEY']}"}
)
manifest_models = manifest_resp.json()["data"]

providers = {
    "manifest": {
        "baseUrl": "http://localhost:2099/v1",
        "api": "openai-completions",
        "apiKey": "$MANIFEST_KEY",
        "models": []
    }
}

for m in manifest_models:
    model_id = m["id"]
    kosha = kosha_models.get(model_id, {})
    providers["manifest"]["models"].append({
        "id": model_id,
        "name": m.get("name", model_id),
        "contextWindow": kosha.get("contextWindow", m.get("context_window", 128000)),
        "maxTokens": kosha.get("maxTokens", m.get("max_tokens", 16384)),
        "reasoning": kosha.get("reasoning", m.get("reasoning", False)),
        "input": kosha.get("input", m.get("input", ["text"])),
        "cost": {
            "input": kosha.get("pricing", {}).get("inputPerMillion", 0),
            "output": kosha.get("pricing", {}).get("outputPerMillion", 0),
            "cacheRead": kosha.get("pricing", {}).get("cacheReadPerMillion", 0),
            "cacheWrite": kosha.get("pricing", {}).get("cacheWritePerMillion", 0)
        }
    })

os.makedirs(os.path.expanduser("~/.pi/agent"), exist_ok=True)
with open(os.path.expanduser("~/.pi/agent/models.json"), "w") as f:
    json.dump({"providers": providers}, f, indent=2)
```
