# pi-openai-api-models-sync: настройка

## Что это

Pi-расширение, синхронизирующее модели из OpenAI-совместимого `/models` эндпойнта и обогащающее их ценами и метаданными о возможностях.

## Установка

```bash
pi install npm:pi-openai-api-models-sync
```

## Как работает

1. Находит все `openai-responses` и `openai-completions` провайдеры в `~/.pi/agent/models.json`.
2. Запрашивает `/models` с аутентификацией провайдера.
3. Загружает метаданные о ценах и возможностях.
4. Пересекает доступные ID моделей с метаданными.
5. Регистрирует модели через `pi.registerProvider()`.

OpenAI-совместимый API — источник истины для доступности моделей. Метаданные дают context windows, output limits, input modalities, token pricing, long-context tiers, reasoning levels.

## Конфигурация провайдера

Провайдер должен уже существовать в `models.json`:

```json
{
  "providers": {
    "my-gateway": {
      "baseUrl": "http://localhost:4000/v1",
      "api": "openai-completions",
      "apiKey": "$GATEWAY_API_KEY",
      "authHeader": true,
      "models": [{ "id": "placeholder" }]
    }
  }
}
```

`models` с плейсхолдером — только bootstrap и fallback. После успешной синхронизации расширение заменяет его для активного процесса Pi.

## Опциональная конфигурация

Создайте `pi-openai-api-models-sync.json` в `~/.pi/agent/` (или в `PI_CODING_AGENT_DIR`):

| Поле | Default | Описание |
|---|---|---|
| `providerId` | все совместимые | Синхронизировать только одного |
| `pricingUrl` | Sub2API metadata repository | URL своего источника метаданных |
| `include` | `[".*"]` | Regex-паттерны |
| `exclude` | audio/realtime/image/embedding | Regex-паттерны исключения |
| `requestTimeoutMs` | 15000 | Таймаут HTTP-запроса |
| `defaults` | zero-cost, text, 128K/16K | Дефолты для моделей без метаданных |

## Проверка

```bash
pi --list-models
```

Или внутри Pi: `/reload`, затем `/model`.
