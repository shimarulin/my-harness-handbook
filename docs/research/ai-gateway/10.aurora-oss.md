# Aurora OSS: настройка и использование

## Что это

Aurora OSS — open-source OpenAI-совместимый AI-шлюз для маршрутизации запросов между несколькими LLM-провайдерами. Поддерживает OpenAI, Anthropic, Gemini, Groq, xAI, Z.ai, vLLM и кастомных провайдеров.

**Ключевые возможности:**
- OpenAI-совместимый API (drop-in замена).
- Provider pools: load balancing между API-ключами (round-robin, least-loaded, weighted).
- Response caching (Redis или SQLite).
- Guardrails: фильтрация контента и проверки безопасности.
- Usage tracking: подсчёт токенов и цен по пользователям и моделям.
- Admin dashboard для управления провайдерами и моделями.
- Prometheus metrics.
- Anthropic ingress: поддержка нативного формата Anthropic API.

**Ссылки:**

## Быстрый старт

### Docker

```bash
docker run -d -p 8080:8080 \
  --name aurora \
  -e GROQ_API_KEY=gsk_your_key_here \
  -e AURORA_MASTER_KEY=your-admin-key \
  aurorahq/aurora:1.0.30
```

### Проверка

```bash
# Health check
curl http://localhost:8080/health

# Список моделей
curl http://localhost:8080/v1/models

# Чат-комплишен
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"groq/llama-3.3-70b-versatile","messages":[{"role":"user","content":"Hello!"}]}'
```

## Конфигурация

Aurora использует трёхуровневую цепочку: код → `config.yaml` → переменные окружения (env vars имеют приоритет).

### Ключевые переменные окружения

| Переменная | Назначение |
|---|---|
| `AURORA_MASTER_KEY` | Admin API key |
| `PORT` | HTTP-порт (по умолчанию 8080) |
| `STORAGE_TYPE` | `sqlite` или `redis` |
| `METRICS_ENABLED` | Включить Prometheus metrics |
| `GUARDRAILS_ENABLED` | Включить guardrails |
| `USAGE_ENABLED` | Включить учёт расходов |
| `COMBOS_ENABLED` | Включить model combos/routing |

## Provider pools (load balancing)

Aurora позволяет объединять несколько API-ключей одного провайдера в пул для балансировки:

- `round-robin` — по кругу;
- `least-loaded` — наименее загруженный;
- `weighted` — с весами.
