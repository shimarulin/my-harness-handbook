# PRD: Data Export to CSV

## Overview

Добавить возможность для пользователей экспортировать их данные (profile, activity, settings) в CSV формате. Это повысит trust и data portability, а также выполнит GDPR требования.

## Problem

**User pain:**
- Пользователи не могут получить свои данные в machine-readable формате
- GDPR Article 20 (Right to data portability) требует export capability
- Support получает ~5 запросов/неделю на manual data export

**Evidence:**
- 23 feature requests за последние 6 месяцев
- 3 GDPR complaints от EU users
- Competitor analysis: 4 из 5 конкурентов имеют export feature

## Goals

1. **Primary**: Пользователи могут self-service экспортировать свои данные
2. **Compliance**: Соответствовать GDPR Article 20
3. **Trust**: Увеличить user trust score с 7.2 до 7.5 (NPS survey)

## Non-goals

- Экспорт в JSON, XML или другие форматы (только CSV в этой фазе)
- Scheduled/recurring exports
- Export admin данных других пользователей
- Import functionality
- Real-time streaming export (batch only)

## Requirements / User Stories

### Story 1: Basic Export
```
As a registered user
I want to download all my data as CSV
So I can keep a personal backup and switch to another service if needed
```
**Priority:** Must

### Story 2: Selective Export
```
As a registered user
I want to choose which data categories to export
So I can get only what I need without overwhelming files
```
**Priority:** Should

### Story 3: Export Status
```
As a registered user
I want to see the status of my export request
So I know when my file will be ready
```
**Priority:** Should

## Constraints & Assumptions

**Constraints:**
- CSV file size limit: 100MB (за file)
- Export processing time: < 5 minutes for typical user
- Data must be complete (all fields user has provided)
- Must work for users with < 10K records (typical) and < 1M records (power users)

**Assumptions:**
- Users understand CSV format
- Async processing acceptable (user waits for email notification)
- No need for encryption of export files in this phase

## Open Questions

| Question | Status | Answer |
|---|---|---|
| Should export include deleted data? | ✅ Resolved | No — only active data |
| Do we need to include metadata (timestamps)? | ✅ Resolved | Yes — each row includes created_at, updated_at |
| Rate limiting? | ✅ Resolved | Max 3 exports per day per user |
