# End-to-End Example: Export Service

Полный пример процесса разработки от идеи до реализации для **системы экспорта данных**.

---

## Описание примера

**Проект**: Пользователи не могут экспортировать свои данные из платформы. Это нарушает GDPR и блокирует корпоративных клиентов.

**Цель**: Реализовать систему экспорта данных в форматах CSV/JSON с асинхронной обработкой.

**Масштаб**: Средняя фича (2-4 недели), одна команда.

## Как использовать этот пример

### Для изучения процесса
Пройдите документы по порядку (1 → 10), обращая внимание на:
- Как каждый артефакт вытекает из предыдущего
- Как требования трассируются до кода
- Как решения фиксируются в ADR

### Для адаптации под свой проект
1. Скопируйте структуру
2. Замените содержимое под свой домен
3. Пропустите ненужные модули (см. [матрицу в README](../../modules/README.md))
4. Добавьте свои модули если нужно

### Для обучения команды
Используйте этот пример как:
- Референс для документации
- Шаблон для новых проектов
- Обучение новых членов команды
