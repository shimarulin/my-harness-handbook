### ACP-адаптеры для Pi

- `svkozak/pi-acp` (upstream, npm `pi-acp`) — https://github.com/svkozak/pi-acp
- `@geohar/pi-acp` — форк upstream: https://pi.dev/packages/@geohar/pi-acp
- `regadas/pi-acp` и `gsd-pi-acp` — не подтверждены, не рекомендуются

Все работают по схеме: ACP-клиент (Zed и др.) ↔ JSON-RPC 2.0 via
stdio ↔ адаптер ↔ `pi --mode rpc`.

> У omp ACP реализован нативно (`omp acp`) — адаптер не нужен.

- Документация: https://omo.dev/docs

**Ключевые файлы в репозитории (изучены при анализе):**

перед коммерческим использованием**.

**Docs:** https://omo.dev/docs/guide/overview.md (подтверждает 3
редакции и OmO Native = omo-senpi).

**Сообщество:** ~69.3k звёзд (весь OmO); Native — beta-канал.

**TypeScript Packages (monorepo):**
- `@oh-my-pi/pi-coding-agent` — CLI и SDK
- `@oh-my-pi/pi-tui` — Terminal UI
- `@oh-my-pi/pi-ai` — multi-provider LLM client
- `@oh-my-pi/pi-catalog` — model catalog
- `@oh-my-pi/pi-agent-core` — agent runtime
- `@oh-my-pi/pi-natives` — N-API bindings
- `@oh-my-pi/omp-stats` — локальный observability dashboard
- `@oh-my-pi/pi-mnemopi` — SQLite memory engine
- `@oh-my-pi/snapcompact` — context compression
- `@oh-my-pi/pi-metaharness` — benchmark runners
- `@oh-my-pi/omptype`, `@oh-my-pi/pi-utils`, `@oh-my-pi/pi-wire`,
  `@oh-my-pi/collab-web` — утилиты и collab

**Уникальные возможности:** debuggers (lldb, dlv, debugpy),

**Дополнительно:** Time-traveling stream rules (TTSR), subagent IRC,
`omp stream`, расширенные model roles (~14).

**Лицензия:** MIT.

**Сообщество:** ~32.8k звёзд; форк Pi от Mario Zechner.

## Протоколы и стандарты

### ACP (Agent Client Protocol)

- Сайт: https://agentclientprotocol.com
- Backed by: Zed; поддерживается JetBrains, GitHub Copilot CLI и др.
- Протокол: JSON-RPC 2.0 over stdio
- Назначение: стандартизация связи IDE ↔ coding agents (аналог LSP)

**Реализации:** omp (нативно), pi-acp (адаптеры, см. выше).

### MCP (Model Context Protocol)

- Используется в: Mastra, Pi, OmO, omp
- Сайт: https://modelcontextprotocol.io
- Назначение: стандартизация доступа к инструментам
- Примеры серверов: context7, grep_app, websearch-реализации
