# Process Framework

Описание процессов, конвенций, шаблонов и примеров для research-driven документации. Переносимо между репозиториями.

## Назначение

Этот каталог — **слой 3** документации: не контент для читателя (`content/`), не рабочее пространство репозитория (`docs/`), а **описание процессов как таковых**. Используется:

- В этом репозитории — как нормативный слой для `docs/`.
- В других проектах — как переносимый фреймворк (копируется или подключается как зависимость).

## Структура

```
tools/process-framework/
├── README.md              # этот файл
├── conventions/           # конвенции: обязательные правила
│   ├── structure.md       #   структура репозитория (три слоя)
│   ├── frontmatter.md     #   frontmatter: схема, таксономии, правила
│   ├── naming.md          #   именование: идентификаторы, slug, директории
│   └── kb-format.md       #   формат статей базы знаний
├── templates/             # шаблоны: переиспользуемые формы (пока пусто)
├── examples/              # примеры: эталоны заполнения (пока пусто)
└── adr/                   # решения о фреймворке процессов (пока пусто)
```

## Принципы

1. **Прескриптивность.** Конвенции — правила, не рассуждения. Проверяемо, исполнимо.
2. **Переносимость.** Нет ссылок на конкретный контент репозитория; только на другие файлы фреймворка.
3. **Прогрессивное раскрытие.** Короткий README; детали — в конвенциях по ссылкам.
4. **Совместимость с AGENTS.md.** Правила для агентов — в корневом `AGENTS.md`; конвенции — детализация.

## Связь с репозиторием

| Слой | Путь | Роль |
|---|---|---|
| Контент | `content/` | Продукт для читателя |
| Рабочее пространство | `docs/` | Производство контента |
| **Фреймворк** | `tools/process-framework/` | **Описание процессов** |

## Использование в других проектах

1. Скопировать `tools/process-framework/` в целевой репозиторий.
2. Адаптировать `conventions/structure.md` под целевую структуру (если отличается).
3. Создать `docs/` и `content/` по конвенции.
4. Корневой `AGENTS.md` ссылается на `tools/process-framework/conventions/` для деталей.
